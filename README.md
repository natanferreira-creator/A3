# Conexão Segura — Educação digital

Página web educativa que ensina a identificar golpes virtuais, proteger dados pessoais e navegar com segurança.

## Funcionalidades

- **Quiz de segurança digital:** 8 perguntas com explicação após cada resposta e pontuação final.
- **Simulador de golpes:** o usuário analisa mensagens fictícias (SMS, e-mail, WhatsApp e app) e decide se são golpe ou legítimas, vendo depois os sinais de alerta.
- **Proteção de senhas:** verificador de força de senha e dicas para criar e proteger senhas.
- **Hábitos seguros:** orientações para navegar com segurança e proteger dados pessoais.

## Tecnologias

HTML, CSS e JavaScript (sem bibliotecas externas).

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos e layout responsivo
- `script.js`: lógica do quiz, do simulador e do verificador de senha

## Como usar

Baixe os três arquivos na mesma pasta e abra o `index.html` no navegador.
